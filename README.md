## Main results

- OULAD: a 2013-trained random forest achieved **0.775 AUROC** (person-bootstrap 95% CI 0.765-0.784) on 9,683 eligible 2014 enrolments with no person overlap with 2013.
- More early active days and stronger recent activity momentum were independently associated with lower Fail/Withdrawn odds, controlling volume, context, workload and early submission completion.
- Moodle: 141 early-arriving user IDs formed three K-Means profiles (silhouette 0.421). The smallest has only six users, and bootstrap stability has a broad range.
- Early active-day spread predicted later participation. The hypothesized independent positive effect of resource diversity was **not supported**.

All findings are exploratory associations, not causal effects. Moodle contains no grade outcome or roster, so inactivity is not classified as academic failure or dropout. The report explains the observation windows, filtering, uncertainty and limitations.

## Reproduce

Python 3.13 was used. Allow roughly 2 GB of memory and 1 GB of disk; runtime depends on hardware. From the repository root:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/download_data.py --moodle "/path/to/MOODLE Data.csv"
python src/analyze.py
python src/robustness.py
python src/build_report.py
python src/verify.py
```

Alternatively, use `uv venv --python 3.13` and `uv pip install -r requirements.txt` before the script commands. The downloader uses Kaggle's public endpoint; if that endpoint changes, manually extract the same mirror to `data/raw/oulad/`. No credentials or signed download URLs are embedded in the code.

Expected layout:

```text
data/raw/oulad/{assessments,courses,studentAssessment,studentInfo,studentRegistration,studentVle,vle}.csv
data/raw/moodle/moodle.csv
```

`results/input_sha256.json` records the exact analyzed files. `verify.py` detects changes against the delivered input manifest. All primary seeds are 610. Bootstrap intervals and plots are generated by the scripts; clustering is evaluated descriptively, not reported as supervised prediction accuracy.

## Design decisions worth checking

- OULAD: registration by day 0, no withdrawal before day 56; predictors days 0-55 only. Zero-click enrolled learners remain. Repeated count rows are retained in the primary model because no event ID proves an export duplicate; deleting exact repeats does not change the association conclusions.
- Train/validation: 2013 enrolments, grouped by student. Test: eligible 2014 enrolments, exclude anybody appearing anywhere in raw 2013 and unseen module-season combinations. The 2014 inference model is separate from the 2013-trained classifier and never tunes it.
- OULAD submissions: only non-banked, non-exam assessments due by day 55, with submissions observed by the cutoff. No score or future-submission leakage.
- Moodle: first observed date anchors the windows, not a verified course start. Include IDs first observed within 28 days. Remove auto-save and SCORM score/status telemetry. Four clustering features use only the first 56 days; future active days use the next 28 days.
- Session durations sum retained within-session gaps, with no terminal padding. They are not verified study time and are not features in the primary hypotheses or clustering.
- Four primary hypothesis p-values use Holm correction; secondary checks are descriptive. A negative M2 result is retained rather than redefined after fitting.
